**Test 2** (`t2_interp_stencil.py`, no solve): this test fills the production `SurfaceField` stencil with the
**exact** reference field and splits the observed error into the interpolation error e_int plus the residual, which is

- [F] Reference check: the exact field at each point reproduces the frozen T_ref to within 4e-8 K.
- [F] nlayer d1: the residual is +0.7530 / +0.1885 / +0.0472 at the centroid and +0.7535 / +0.1887 / +0.0473 at the
  max. These are identical, with ratio 4.00 (second order, monotone).

  - At the max it is -0.748 / -0.110 / -0.052, with stencil coordinate tx = 0.747 -> 0.995 -> 0.489.
  - d4.max shows the same pattern. Its corrected GCI is 0.161 K, against inf observed.
- [F] Corrected GCIs (A4 rule applied to f_L - e_int(L)):

  | value | observed GCI | corrected GCI |
  |---|---|---|
  | d1.max | inf | 0.177 |
  | d4.max | inf | 0.161 |
  | mms die_max | inf | 0.061 |
  | mms die_centroid | 0.595 | 0.0625 |
  | mms overhang | 0.201 | 0.0068 |

- [I] Mechanism. Bisecting a locally uniform cell-centred grid maps the stencil coordinate as ξ → (2ξ + ½) mod 1
  (derived; the observed 0.747 → 0.994 → 0.488 follows it). The linear-interpolation remainder is
  -½ ξ(1-ξ) h² T'' (Lagrange remainder; e.g. Süli & Mayers, *An Introduction to Numerical Analysis*, CUP 2003, ch. 6).
  Its coefficient therefore follows a Bernoulli-shift orbit. The only fixed point is ξ = ½, a point on a grid line that
  persists under bisection, which is why centroids are clean. ξ = 0 reaches that fixed point after one step, which is
  why d3.centroid shows p_obs = 7. Three-grid GCI (Roache 1998, ch. 5) assumes f_L = f* + C h_L^p with a fixed C, and
  these values violate that by construction. The estimator then correctly reports "divergent" for a quantity that is
  not a discretisation sequence.
- [F] This was visible before registration. The smoke dev rows already had one divergent manufactured value and A4 = inf
  (`research/notes/o006-e006-design.md` §4).

## 3. Conclusion
- **A1/A2 (class: model, confidence 0.85 on the mechanism).** The frozen grid rule fixes `Z_CELLS = 2` cells per layer
  whatever the layer's thickness. Its docstring justifies this by tests on generator geometry ("none changed a reported
  value by more than 0.02 K").
  - [F] On the 10 mm single-layer Muzychka plates (Cases 1a and 2: high flux density over thick, low-k plates), L2 has
    dz = 1.25 mm. That leaves 0.12-0.14 K of through-thickness discretisation error at the source means.
  - [I] The verified code converges to a validated reference at second order. The error correlates with a geometric
    variable (layer thickness / dz). It is a numerical-model assumption that fails in a regime the generator stacks do
    not contain. It is not a code defect, and nothing found here says the L2 solver is wrong.
- **A4 (class: experimental, confidence 0.9).** A4 applies the three-grid GCI to bilinear interpolants at fixed
  off-lattice points. These have no asymptotic error expansion under bisection. The FV field converges cleanly at those
  points.
  - [F] Without these four interpolation-affected values, A4 over all values would be 0.393 K (case2 s2.mean).
  - [I] A4 being +inf is a measurement artefact, not evidence that the solver fails to converge.
- **Overall class: model** (primary; it alone keeps A1/A2 unmet), with a secondary experimental defect in A4.
  Confidence 0.7 in the label. A referee could defensibly call the A1/A2 part "experimental" instead, on the grounds that
  Cases 1a and 2 lie outside the DBC regime the decision concerns.
- [F] The pre-registered decision_if_inconclusive is "Otherwise same as fail", which means the scikit-fem fallback.
  O006 has max_evaluations 1, now used.
